Privacy policy

AccessScan is a local tool with nothing to track. This page explains exactly what data exists and where it goes — which is mostly nowhere.

What data exists

Only two things: the URLs you submit and the scan results for them. Both live in the server process's memory (RAM) on your own machine — the same place the tool itself runs. There is no database, no log file of scans, and nothing written to disk.

Your browser doesn't store anything either: no cookies, no localStorage, no session state. Close the tab or restart the server and everything is gone.

What leaves your machine

Your browser talks only to the AccessScan server on 127.0.0.1 — your own computer. From there, the one thing that "leaves" is the point of the tool itself: the server fetches the website URL you gave it and runs an accessibility check on the rendered page, exactly as your browser would. That target site sees a normal page request (with a User-Agent identifying AccessScan).

There are no third-party requests: no analytics, no telemetry, no CDN-hosted scripts or fonts, no external fonts or trackers. Every script and stylesheet is served from the same local server. The only outbound links on this site are documentation links (like the axe-core rule reference) that load only if you click them.

What we don't do

  • No cookies or tracking of any kind
  • No accounts, sign-ups, or logins
  • No analytics or usage reporting
  • No third-party SDKs or external services
  • No payments — the tool is free
  • No database and no cloud storage

Data retention

Scan records are kept in memory only, capped at the 20 most recent scans, and are deleted when the server process stops. If you want a copy of a report, export it (HTML, JSON, or PDF) before restarting — exports are generated on your machine and downloaded to your browser like any normal file.

Contact

Questions or concerns: open an issue at github.com/Afkhomie/AccessScan/issues. AccessScan is operated by Afkhomie via GitHub.

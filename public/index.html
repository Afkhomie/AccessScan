    How it works

    1. Paste a URLAny public http(s) page. Private/internal addresses are blocked.
    2. We load it in a headless browserSame rendering engine users get, then axe-core checks the DOM against WCAG 2.x rules.
    3. You get a plain reportIssues grouped by severity with the exact element, a code snippet, and a fix hint. Optionally scan up to 10 pages including same-site links.

    AccessScan runs entirely on this machine — no accounts, no payments, no database, no cloud. MIT licensed. · WCAG rule reference
